# ⚙️ Microprocessadores e Microcontroladores — STM32 🧠

Este repositório reúne **projetos desenvolvidos na disciplina de Microprocessadores e Microcontroladores (2025.1)**, utilizando a **linguagem C** no microcontrolador **STM32F407VET6**, com desenvolvimento realizado no **STM32CubeIDE**.

📌 **Sobre os Projetos**

🔧 **Sistemas Embarcados na Prática**
Os projetos exploram conceitos fundamentais de **controle, automação e programação embarcada**, integrando hardware e software por meio de sensores e atuadores.

🧠 **Conceitos Trabalhados**

* Programação em C para sistemas embarcados
* Configuração de periféricos do STM32
* Timers, GPIO, ADC e PWM
* Interrupções e comunicação com dispositivos externos

🔌 **Sensores e Atuadores Utilizados**

* LEDs 💡
* Buzzer 🔊
* Motor DC ⚙️
* Servomotor 🌀
* Joystick 🎮
* Display LCD 📟
* Sensor de temperatura 🌡️
* Sensor ultrassônico 📡

🧩 **Arquitetura dos Projetos**
Os códigos são organizados de forma modular, facilitando:

* Manutenção e depuração
* Reutilização de código
* Expansão dos projetos

🎯 **Objetivos**

* Aplicar conceitos teóricos de microcontroladores
* Desenvolver sistemas embarcados funcionais
* Integrar sensores e atuadores
* Consolidar conhecimentos em controle e automação

🛠️ **Tecnologias**

* Linguagem C
* STM32F407VET6
* STM32CubeIDE
* HAL / drivers do STM32

📚 **Observação**
📘 Projetos desenvolvidos com **fins acadêmicos**, voltados ao aprendizado prático em **microprocessadores, microcontroladores e sistemas embarcados**.
